# Software Testing

This folder documents the testing process for the Smart Solutions multiplayer Life Counter Website.

## Testing Objectives

- Verify player creation and removal.
- Verify life point calculations.
- Verify individual player resets and Reset All.
- Verify input validation and error messages.
- Verify the minimum two-player requirement.
- Verify browser compatibility and responsive layout.
- Verify accessibility and calculation accuracy.

## Testing Status

Final testing is pending.

Test results will be recorded after checking the website against the Final Software Requirements Specification.
