# Project Website

Smart Solutions is developing a multiplayer Life Counter Website for Magic: The Gathering.

## Website Pages

- [Team Homepage](../index.html) – Introduces the team and project.
- [Life Counter Application](../life-counter.html) – Allows two or more players to manage their life points.

The website files are maintained in the root directory for GitHub Pages deployment.
