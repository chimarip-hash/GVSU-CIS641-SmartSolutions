Project Overview

We are developing a website to help two Magic: The Gathering players keep track of their life totals. Each player starts with 20 life points. Users can enter player names, add or subtract an amount of life, and reset both totals for a new game.

Our goal is to provide a simple way to track life totals instead of using paper or dice. We plan to use HTML for the page structure, CSS for the layout, and JavaScript for the life counter functions.

Current Progress

We have prepared a project proposal, initial diagrams, and a website demo. We are reviewing the requirements and discussing improvements. The full website is still being developed.
